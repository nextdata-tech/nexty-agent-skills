# S3 inspection

- **Driver:** `nxd:s3:1.0.0` — category Storage, storage kind **file**
- **Plugin:** `scripts/drivers/s3.py` ✓ implemented
- **Client:** `boto3` (lazy import)

## Attributes

`bucket`, `region_name`, `aws_access_key_id`, `aws_secret_access_key`, `file_type` (default format).

## Recipe

1. List objects with `client.list_objects_v2(Bucket=bucket)` (paginate via `ContinuationToken`). Skip keys ending in `/`.
2. Infer each object's schema, dispatching on the file **extension**:
   - **.csv** — ranged `get_object` for the first ~64 KB, parse header + up to 100 rows, infer column types.
   - **.parquet** — read the footer schema only: `pyarrow.parquet.ParquetFile(buf).schema_arrow`.
   - **.json / .jsonl** — read the first record, collect keys and value types.
   - **.avro** and other binary formats — record the format; do not attempt a column schema.
3. Group objects with an identical `(schema fingerprint, format)` into one logical asset (see Schema-fingerprint grouping in `../service-inspection.md`). Segments that vary within a group are partition keys.
4. Per asset record the common path prefix as locator, plus schema, partition keys, `object_count`, total `bytes`, and max `LastModified`.

On huge buckets, infer schema from one representative object per fingerprint, not every object.

## Read-only

Only `list_objects_v2`, `get_object`, `head_object`. Never `put_object`, `delete_object`, `copy_object`.

Role badges

roles[] · a set, not a type
known kinds
pkdim metric→ customers
unknown kind

Unreachable. The role vocabulary is closed (dimension, metric, join, primary_key) and an unknown kind fails the read outright, so no payload carrying one ever reaches a renderer. Render the read error, not a degraded badge.

pii — the only semantic color

Role kinds carry no colour. They are told apart by label. If metric were amber, amber would stop meaning warning and truncated would no longer stand out.
